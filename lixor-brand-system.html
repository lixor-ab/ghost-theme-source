Logo

Two colourways. Each is a self-contained stamp — the background is part of the mark.

Black colourway

White letterforms on black. Use when you want contrast and visual weight — on cream pages, dark sections, or anywhere the stamp needs to pop.

White colourway

Black letterforms on white. Use on dark or mid-tone backgrounds where a lighter stamp is the right visual choice.

The pink dot rule: The dot is Signal Pink — it is part of the mark. Never recolour it, never swap it for lavender. It is the one place in the brand where pink is non-negotiable.
✓ DO
  • Use either colourway as a contained stamp — the background is part of the logo
  • Give it clear space equal to the width of the pink dot on all sides
  • Scale proportionally — never stretch or squish
✗ DON'T
  • Recolour the dot to lavender or any other colour
  • Remove or replace the background — it is not optional
  • Rotate, skew, add drop shadows, or apply filters

Usage Rules

The decision is already made. Look it up, don't think about it.

Context ● Signal Pink ● Soft Lavender Notes
Ghost · Article body One deliberate word in a headline. A dot. A gesture. Never a link. All link underlines. Callout borders. Pink is never automatic.
Ghost · Article cards — Top accent rule. Category pill. Pink stays out of recurring UI.
Ghost · Buttons — Secondary button border + fill. Primary CTA: ink bg + white text.
Newsletter header — — Near-black background only. Clean.
Newsletter body One expressive moment per issue, if needed. Links. Callout border. Tags. One callout per issue maximum.
Mermaid diagrams Entry node, key decision, outcome. Process nodes, structural steps. Cream background always.
LinkedIn · Light tile One word or stat. Category pill. Bottom bar. One accent only per tile.
LinkedIn · Dark tile One word in headline only. — Near-black bg. Pink = one word max.
Illustrations / graphics Use freely. Use freely. Full creative palette available here.
✓ DO
  • Use pink once per section at most, when chosen
  • Let lavender handle all links and interactive states
  • Use cream backgrounds for long reading
  • Alternate cream and dark for page rhythm
  • Use Fraunces italic for the one expressive moment
  • Keep body text max 65 characters wide
✗ DON'T
  • Use pink for links, buttons, or recurring UI elements
  • Mix both accents in the same small element
  • Use italic in Lato body text
  • Go dark more than two sections in a row
  • Use the creative palette in Ghost or newsletter UI
  • Add a third accent color to web or newsletter

07

Mermaid Diagrams

Node colors follow the same logic as the rest of the system. No new decisions.

Node color logic
Decision / goal Entry points, key decisions, the outcome you're driving toward. "This matters most." Process / system Structural steps, repeating processes, how-it-works nodes. Neutral step Default steps, sub-processes — no emphasis needed. External / context External systems, stakeholders, things outside your control. Deprioritized Parked ideas, future work. Dashed border signals "not now."
Example — discovery flow
Stakeholder ask → Discovery sprint → Opportunity clear?
YES ↓ Shape solution → Prioritize → Ship
NO ↓ Park + document → revisit in 90 days

Diagrams always use the cream background — readable in Ghost articles and newsletter embeds without extra config.
